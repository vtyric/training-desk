# Инструкции для команды студентов

Команда администрирует выданный стенд и разрабатывает собственный сервис обработки обращений. Keycloak и Service Desk работают на сервере, приложение команды — сначала локально, затем на своём стенде. Доступ к исходникам серверного контура для интеграции не требуется.

Работа состоит из трёх частей:

1. [Пользователи и роли Keycloak](students/01-keycloak-and-roles.md) — создание учётных записей, права Service Desk и роли собственного приложения.
2. [Вход через OpenID Connect](students/02-openid-connect.md) — регистрация localhost и стенда, готовая форма входа Artsofte, токены и выход.
3. [Интеграция с Service Desk](students/03-service-desk.md) — локальный proxy, webhook, назначение исполнителя, переписка и статусы.

В примерах `auth.example.ru`, `desk.example.ru` и `team1.example.ru` обозначают адреса, которые команда получает при передаче стенда. Они заменяются на реальные адреса.

Для управления пользователями нужен администратор Keycloak. Для изменения JSON Service Desk — учётка с ролью `service-desk:admin`. Команде выдаются оба доступа; один автоматически не даёт другой.
