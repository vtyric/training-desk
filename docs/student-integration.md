# Три инструкции для команды студентов

Студенты администрируют выданный учебный стенд через Keycloak и API Service Desk, а своё приложение разрабатывают в отдельном репозитории. Исходники серверного контура для подключения не нужны.

Инструкции читаются по порядку:

1. [Keycloak: пользователи и роли](students/01-keycloak-and-roles.md). Административные доступы, создание пользователя, группы, роли внешнего Service Desk и собственного сервиса, claims токена.
2. [OpenID Connect в вашем проекте](students/02-openid-connect.md). Настройка клиента для localhost и стенда, использование готовой формы входа Artsofte, примеры SDK, проверка токена на backend и выход.
3. [Интеграция с Service Desk](students/03-service-desk.md). Локальный proxy, HTTPS-туннель для webhook, настройки получателя, подпись и повторы, распределение, статусы, переписка и закрытие обращения.

Адреса `auth.example.ru`, `desk.example.ru` и `team1.example.ru` — примеры. Вместо них используются адреса выданного стенда и приложения команды.

Администратор Keycloak и администратор службы поддержки — два разных доступа. Первый управляет пользователями/клиентами, второй — JSON настроек Service Desk. Обе настройки выполняет команда, которой выданы соответствующие административные учётные записи.
