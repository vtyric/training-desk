# Навыки русской редакции

В репозитории сохранены два навыка из [N1arko/redaktura-skills](https://github.com/N1arko/redaktura-skills/tree/d1ebaff4fb8b97f939826a1cac284c10303be6f1):

- [redaktura](../.agents/skills/redaktura/SKILL.md) — проверка смысла, структуры, тональности, предложений и слов в документации.
- [ux-copy](../.agents/skills/ux-copy/SKILL.md) — названия, подписи, состояния, ошибки и действия интерфейса.

Навыки и примеры принадлежат Людмиле Сарычевой и Никите Архипову и распространяются по лицензии [Creative Commons Attribution 4.0](../.agents/skills/LICENSE-CREATIVE-COMMONS-BY-4.0). Исходные файлы сохранены для атрибуции. Локальные изменения находятся в документации проекта, а не в копиях навыков.

При редактуре технических материалов сначала сохраняются точные API-пути, JSON-поля, роли, статусы и ограничения. Человеческие подписи и объяснения упрощаются; технические идентификаторы не переводятся.
